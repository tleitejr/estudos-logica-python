## 🧠 O que é lógica de programação?

Lógica de programação é a **capacidade de organizar o pensamento** para resolver problemas de forma estruturada, usando sequências de instruções que o computador possa executar.

Ela é a base de qualquer linguagem de programação — seja Python, JavaScript, Java, C# etc.

---

## 🔑 Conceitos fundamentais

### 1. Variáveis
Espaços na memória que armazenam valores.

```python
nome = "Aline"
idade = 25
```

### 2. Tipos de dados
- `str` — texto
- `int` — números inteiros
- `float` — números decimais
- `bool` — verdadeiro/falso (`True` / `False`)

### 3. Operadores
- Aritméticos: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- Comparação: `==`, `!=`, `>`, `<`, `>=`, `<=`
- Lógicos: `and`, `or`, `not`

### 4. Estruturas condicionais
Tomada de decisão com `if`, `elif` e `else`.

### 5. Laços de repetição
Repetição de instruções com `for` e `while`.

### 6. Funções
Blocos reutilizáveis de código:

```python
def soma(a, b):
    return a + b
```
