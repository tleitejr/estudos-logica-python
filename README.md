# 🐍 Estudos de Lógica com Python

Repositório criado para praticar **lógica de programação** utilizando **Python**, com o objetivo de servir como material de estudo colaborativo e portfólio de aprendizado.

> 💡 Todo o conteúdo teórico detalhado está disponível na [Wiki](../../wiki).  
> 🗂 As tarefas e melhorias estão organizadas no [Project Kanban](../../projects).

---

## 🎯 Objetivo

- Praticar conceitos fundamentais de lógica de programação.
- Servir como base de consulta para iniciantes.
- Demonstrar o uso dos recursos do GitHub (Issues, Projects, Wiki, Pull Requests e Codespaces).

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/estudos-logica-python.git
   ```
2. Entre na pasta:
   ```bash
   cd estudos-logica-python
   ```
3. Execute qualquer arquivo:
   ```bash
   python algoritmos/variaveis.py
   ```

> 💻 Você também pode executar diretamente no navegador usando um **Codespace** (menu **Code → Codespaces**) — sem instalar nada localmente.

## 🤝 Como contribuir

1. Abra uma **Issue** sugerindo melhoria ou correção.
2. Crie um **fork** do repositório.
3. Crie uma **branch** com sua alteração:
   ```bash
   git checkout -b minha-contribuicao
   ```
4. Faça o **commit** e o **push**.
5. Abra um **Pull Request** explicando sua mudança.

Toda contribuição é bem-vinda! 💚
